# 0.4.0 自动配置匹配与自定义提示词

## 功能

按完整目标 UMO 匹配 AstrBot 官方配置路由，生成时传入 `config_id`，使用对应配置档的人格、模型与工具设置。提示词可编辑、保存和恢复默认；保留服务端人格，不修改全局路由。

## 路由边界

- [RouteResolver](<../android/src/cn/local/micompanion/RouteResolver.java>)保留服务端 JSON 路由顺序，按 first-match 匹配，不仅比较机器人 ID。
- 无匹配才使用默认配置。读取失败、权限不足、失效配置、非法 JSON、重复键、不支持的模式或资源超限均拒绝，不静默回退。
- 官方 chat 的 WebChat 精确路由可能被更早通配规则覆盖；预检模拟其更新顺序，有冲突则停止。
- 旧缓存正文无配置来源时暂停；重试时配置发生变化也不混用旧正文。
- GET 与 POST 之间没有服务端原子版本锁，配置 ID 固定不等于人格内容快照；不复制目标会话单独切换的人格或记忆。

## 提示词与投递

- 提示词随任务快照冻结。恢复默认只修改草稿，仍需保存；最多 4000 Unicode 码点，超限不静默截断。
- 固定安全约束要求遵守事实、区分缺失、不作诊断、不执行数据中的指令，不可由自定义提示词覆盖。
- 正文必须收到完整 SSE end 和正常 EOF；工具调用或错误阻止转发。超过 500 码点时优先句末裁剪，不再次调用模型。
- 每个副作用屏障检查连接、目标、HTTP 开关、Key；自动任务额外检查监控授权。设置变化无法撤销已发起的请求。
- 官方没有单请求硬禁工具能力，客户端拒绝转发不能撤销服务端已执行的工具。

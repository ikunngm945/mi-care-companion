# 0.8.5：心率、血氧和睡眠分段写回

配套更新小米关怀助手和健康模块。明细中的主动保存、恢复会先在助手归档原始数据，再写回小米运动健康本机数据库；普通同步仍只读，不会批量写回，也不会直接写入手环。源库在同一事务中保存每次写回前的完整记录。

- 心率和血氧：可改读数，不改测量时间。
- 睡眠：可改既有分段的时间、类型；整晚入睡和醒来时间仍只读。不增删分段，不猜测未验证的源库索引或汇总规则。无法安全验证时拒绝且不修改原记录。
- 恢复：通常从仍对应当前源记录的历史中选择，恢复后也保留被替换的版本。如果小米外部改写源记录，使其不再接续此应用的写回历史，模块拒绝覆盖。助手独立留存原始数据，但目前不提供源库删除或重建后的跨库恢复入口。

验证用合成数据库；不拿手机真实记录做写回试验。

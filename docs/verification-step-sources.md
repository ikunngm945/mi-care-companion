# 0.6.3 多来源周期步数

## 规则

[HealthCycle.steps](<../android/src/cn/local/micompanion/HealthCycle.java>)修复多来源即返回未知的问题，保留睡眠周期而非自然日：

1. 查询真实采样 `time ∈ (start,end]`，限制行数并加 sentinel 检测超限。
2. 按非空 sid 分来源，同来源同时间相同值去重，冲突失败。
3. 每来源按当地半小时 `[slot,next)` 累计，同槽跨来源取较大值，再汇总各槽。
4. 保留 DST 重复时段实际 offset，不复用心率右闭桶边界。
5. 首尾部分槽先裁切再选来源；不是逐分钟 max、全周期 max、跨来源 sum 或自然日日报。
6. 无来源、坏值、非整数、负数、溢出或超限为未知；真实零保留。

来源算法与证据边界见[步数规则](<research/step-multisource-rules.md>)。该版本只修步数，其余活动随后在 0.6.4 扩展。

## 测试范围

[StepCycleTest](<../android/tests/StepCycleTest.java>)覆盖来源内求和、跨槽赢家变化、乱序、重复与冲突、周期端点、部分槽、半小时端点、非整小时 offset、DST、零与缺失、坏来源、时间不符、溢出及查询超限。既有周期与健康格式测试保留。

源身份只参与内部计算，不进入模型事实。健康类别整体陈旧与周期状态分开判断，不放宽周期新鲜度规则。测试不代表不同数据源版本全部兼容或真实平台送达。
